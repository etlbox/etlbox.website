Real deep clones

CloneX() copies nested objects, collections, arrays, and dictionaries — including cycles — without shared identity.

Clone into existing objects

CloneXTo() fills a different type or an instance you already have. Extra target fields stay put.

Dynamics included

ExpandoObject and mixed graphs work the same way as typed POCOs — including clone-into a DTO.

Very fast

Built for hot paths. Competitive with specialized cloners on simple graphs — and still correct when the graph gets hard.
