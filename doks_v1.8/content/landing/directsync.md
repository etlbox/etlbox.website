ETLBox DirectSync is a Windows desktop application and command-line tool for moving data between heterogeneous systems with minimal setup. It is built on the ETLBox engine, scales to very large datasets through streaming, and offers a modern UI plus scriptable automation via JSON configuration and the `DirectSync` CLI command.
