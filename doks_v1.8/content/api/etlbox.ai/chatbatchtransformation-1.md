  <h1 id="ETLBox_AI_ChatBatchTransformation_1" data-uid="ETLBox.AI.ChatBatchTransformation`1" class="text-break">Class ChatBatchTransformation&lt;TInput&gt;</h1>
  <div class="markdown level0 summary"><p>Sends each batch to an <span class="xref">Microsoft.Extensions.AI.IChatClient</span> as one request and emits the returned rows in the order they came back.
The batch is sent as <code>{&quot;Items&quot;:[...]}</code> and the same envelope is expected in the response.
Set <a class="xref" href="/api/etlbox.ai/chatbatchtransformation-2#ETLBox_AI_ChatBatchTransformation_2_RequireSameItemCount">RequireSameItemCount</a> to enforce one item per input row. Default batch size is 10.</p>
</div>
