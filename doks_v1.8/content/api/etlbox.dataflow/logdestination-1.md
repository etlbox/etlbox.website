  <h1 id="ETLBox_DataFlow_LogDestination_1" data-uid="ETLBox.DataFlow.LogDestination`1" class="text-break">Class LogDestination&lt;TInput&gt;</h1>
  <div class="markdown level0 summary"><p>A destination that writes each incoming record into a log output using a Microsoft ILogger.
Every record is serialized (by default using the same json serialization that is used
for the error output) and logged with the defined <a class="xref" href="/api/etlbox.dataflow/logdestination-1#ETLBox_DataFlow_LogDestination_1_LogLevel">LogLevel</a> and <a class="xref" href="/api/etlbox.dataflow/logdestination-1#ETLBox_DataFlow_LogDestination_1_MessageTemplate">MessageTemplate</a>.
If the input type is <a class="xref" href="/api/etlbox/etlboxerror">ETLBoxError</a>, a specialized default message template and
the log level Error are used - this allows to link the error output of any component
directly into a LogDestination.</p>
</div>

  <h4 id="ETLBox_DataFlow_LogDestination_1_MessageTemplate" data-uid="ETLBox.DataFlow.LogDestination`1.MessageTemplate">MessageTemplate</h4>
  <div class="markdown level1 summary"><p>The structured message template used for logging each record.
The template receives three arguments: the current record number ({progressCount}),
the current time or report time of the error ({time}) and the serialized record ({recordAsJson}).
For records of type <a class="xref" href="/api/etlbox/etlboxerror">ETLBoxError</a>, four additional arguments are passed:
{errorText}, {context}, {source} and {exceptionType}.
If not set, <a class="xref" href="/api/etlbox.dataflow/logdestination-1#ETLBox_DataFlow_LogDestination_1_DefaultMessageTemplate">DefaultMessageTemplate</a> is used (or <a class="xref" href="/api/etlbox.dataflow/logdestination-1#ETLBox_DataFlow_LogDestination_1_DefaultErrorMessageTemplate">DefaultErrorMessageTemplate</a>
for records of type <a class="xref" href="/api/etlbox/etlboxerror">ETLBoxError</a>).</p>
</div>
