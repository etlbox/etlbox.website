  <h1 id="ETLBox_AI_EmbeddingBatchTransformation_1" data-uid="ETLBox.AI.EmbeddingBatchTransformation`1" class="text-break">Class EmbeddingBatchTransformation&lt;TInput&gt;</h1>
  <div class="markdown level0 summary"><p>Creates embeddings for a batch of rows with one generator call and writes each vector
back into the corresponding row object. The default batch size is 64.</p>
