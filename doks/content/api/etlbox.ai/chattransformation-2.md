  <h1 id="ETLBox_AI_ChatTransformation_2" data-uid="ETLBox.AI.ChatTransformation`2" class="text-break">Class ChatTransformation&lt;TInput, TOutput&gt;</h1>
  <div class="markdown level0 summary"><p>Sends each incoming row as JSON to an <span class="xref">Microsoft.Extensions.AI.IChatClient</span> and writes the returned object back into the data flow.
Typed output requests a JSON schema derived from <code class="typeparamref">TOutput</code>; <a class="xref" href="https://learn.microsoft.com/dotnet/api/system.dynamic.expandoobject">ExpandoObject</a> output uses JSON mode.</p>
